Основний сценарій

                        
    
                            
  1. Виберіть існуючу сесію або введіть нову назву у верхньому блоці.
    2. 
                            
  2. Завантажте дані з розкладу, API або файлу.
    3. 
                            
  3. Перевірте таблицю через фільтри, проблеми та зведення по днях.
    4. 
                            
  4. Виправляйте записи прямо в таблиці.
    5. 
                            
  5. Виділяйте потрібні рядки та застосовуйте пакетні дії.
    6. 
                            
  6. Перегляньте зміни перед публікацією або експортуйте файл.
    7. 
                        

                    

                    

                        
Фільтри

                        
    
                            
  • Пошук зверху шукає по всій таблиці.
    • 
                            
  • Фільтри по колонках розташовані в шапці таблиці.
    • 
                            
  • Дата від/до обмежує ручний період.
    • 
                            
  • Тільки проблеми показує конфлікти, попередження, пропуски та дублі.
    • 
                            
  • Скинути фільтри очищає весь поточний відбір.
    • 
                        

                    

                    

                        
Робота з рядками

                        
    
                            
  • Редагуйте предмет, групу, викладачів, форму, дату, час і аудиторію прямо в таблиці.
    • 
                            
  • Клік по рядку відкриває картку деталей.
    • 
                            
  • Виділити відфільтровані вибирає всі рядки поточного виду.
    • 
                            
  • Пакетні дії внизу змінюють вибрані рядки.
    • 
                            
  • -1 день / +1 день зсуває дати вибраних рядків.
    • 
                        

                    

                    

                        
Інструменти

                        
    
                            
  • Групування збирає таблицю за датою, групою, викладачем або формою.
    • 
                            
  • У панелі Інструменти можна перемкнути Таблиця / Календар.
    • 
                            
  • Там само можна приховати зайві колонки.
    • 
                            
  • Нормалізувати викладачів приводить імена до одного стилю.
    • 
                            
  • Порівняти з API показує локальні, серверні та змінені записи.
    • 
                        

                    

                    

                        
Версії та безпека

                        
    
                            
  • Чернетка зберігається автоматично.
    • 
                            
  • Знімок версії зберігає поточний стан таблиці.
    • 
                            
  • Можна відновити один з останніх 12 знімків.
    • 
                            
  • Undo / Redo працюють для більшості правок.
    • 
                        

                    

                    

                        
Експорт

                        
    
                            
  • Оберіть режим: відфільтровані, усі або вибрані.
    • 
                            
  • Режим застосовується до Excel, Word і копіювання таблиці.
    • 
                            
  • Перед публікацією перевірте сесію, форму навчання та список видалень.

3. Перевірте чернетку

            
Перевіряються всі рядки, включно з прихованими фільтрами. Час та аудиторія обов'язкові для іспитів. Рекомендації щодо навантаження потребують рішення методиста.

            
Додайте записи для перевірки.

            
    
        
    
        
    
            
    4. Перегляньте зміни та опублікуйте
    
            
    Публікація замінює всі записи вибраної сесії та форми навчання. Інші форми зберігаються. Фільтри таблиці не обмежують публікацію. Попередня версія доступна в керуванні сесіями.
    
            
    
                
                
            
    
            
            
    Зміни ще не перевірені.
